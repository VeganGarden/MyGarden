# 优化因子库子类别显示和筛选功能

## 目标

1. 将"子分类"列标题改为"子类别（食材分类）"
2. 对于食材因子，显示食材类别管理页面中定义的类别名称
3. 对于其他因子，显示subCategory值
4. 添加子类别筛选框，根据当前选择的"分类"动态显示选项

## 实现方案

### 1. 修改表格列显示逻辑

**文件**: `admin-web/src/pages/carbon/FactorLibrary.tsx`

- 修改列标题为"子类别（食材分类）"
- 在组件中加载食材类别列表，建立 `subCategory -> categoryName` 的映射
- 修改列的 `render` 函数：
- 如果 `category === 'ingredient'`，通过 subCategory 查找对应的类别名称显示
- 否则直接显示 subCategory 值
```typescript
// 加载食材类别列表
const [categoryMap, setCategoryMap] = useState<Map<string, string>>(new Map())

// 在useEffect中加载类别数据
useEffect(() => {
  const loadCategories = async () => {
    try {
      const result = await ingredientStandardAPI.category.list({
        status: 'active',
        pageSize: 1000
      })
      if (result?.code === 0 && result.data?.list) {
        const map = new Map<string, string>()
        result.data.list.forEach((cat: IngredientCategory) => {
          if (cat.mapping?.factorSubCategory) {
            map.set(cat.mapping.factorSubCategory, cat.categoryName)
          }
        })
        setCategoryMap(map)
      }
    } catch (error) {
      console.error('加载食材类别失败:', error)
    }
  }
  loadCategories()
}, [])

// 修改列render
render: (subCategory: string, record: CarbonEmissionFactor) => {
  if (record.category === FactorCategory.INGREDIENT) {
    // 食材因子：显示类别名称
    const categoryName = categoryMap.get(subCategory) || subCategory || '-'
    return categoryName
  } else {
    // 其他因子：显示subCategory
    return subCategory || '-'
  }
}
```




### 2. 添加子类别筛选框

**文件**: `admin-web/src/pages/carbon/FactorLibrary.tsx`

- 在筛选区域添加子类别筛选框
- 根据当前选择的 `category` 筛选值动态显示选项：
- 如果选择了"食材"分类，显示所有食材类别名称（从食材类别管理页面获取）
- 如果选择了其他分类或未选择，显示所有subCategory值（从当前数据中提取）
- 筛选逻辑：在 `listFactors` API调用中添加 `subCategory` 参数
```typescript
// 添加状态
const [subCategoryOptions, setSubCategoryOptions] = useState<Array<{value: string, label: string}>>([])

// 根据category筛选值动态更新选项
useEffect(() => {
  const updateSubCategoryOptions = async () => {
    if (filters.category === FactorCategory.INGREDIENT) {
      // 食材：显示类别名称
      const result = await ingredientStandardAPI.category.list({
        status: 'active',
        pageSize: 1000
      })
      if (result?.code === 0 && result.data?.list) {
        const options = result.data.list
          .filter((cat: IngredientCategory) => cat.mapping?.factorSubCategory)
          .map((cat: IngredientCategory) => ({
            value: cat.mapping.factorSubCategory,
            label: cat.categoryName
          }))
        setSubCategoryOptions(options)
      }
    } else {
      // 其他分类：从当前数据中提取所有subCategory值
      const uniqueSubCategories = Array.from(
        new Set(dataSource.map(f => f.subCategory).filter(Boolean))
      ).map(subCat => ({
        value: subCat,
        label: subCat
      }))
      setSubCategoryOptions(uniqueSubCategories)
    }
  }
  updateSubCategoryOptions()
}, [filters.category, dataSource])

// 添加筛选框
<Select
  placeholder="子类别"
  allowClear
  style={{ width: 150 }}
  value={filters.subCategory}
  onChange={(value) => handleFilterChange('subCategory', value)}
  disabled={!filters.category && filters.category !== FactorCategory.INGREDIENT}
>
  {subCategoryOptions.map(opt => (
    <Option key={opt.value} value={opt.value}>{opt.label}</Option>
  ))}
</Select>
```

## 注意事项

1. **性能优化**: 食材类别列表只需加载一次，使用useEffect和状态缓存
2. **数据同步**: 如果食材类别管理页面更新了类别，因子库页面需要刷新才能看到最新类别名称
3. **筛选逻辑**: 后端云函数 `carbon-factor-manage/index.js` 的 `listFactors` 函数已支持 `subCategory` 参数筛选，无需修改后端
4. **空值处理**: 对于没有subCategory的因子，显示"-"
5. **筛选联动**: 当切换"分类"筛选时，清空"子类别"筛选值，并更新选项列表
