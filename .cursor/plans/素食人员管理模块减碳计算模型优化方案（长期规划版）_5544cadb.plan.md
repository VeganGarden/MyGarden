# 素食人员管理模块减

碳计算模型优化方案（长期规划版）

## 一、方案定位

### 1.1 设计原则

由于平台处于**研发阶段，尚未投入实际业务应用**，本方案采用**长期规划目标**，直接设计一个完善的、基于科学研究的减碳计算模型，无需考虑渐进式保守策略。

### 1.2 核心目标

1. **建立科学的计算模型**：基于权威研究数据，建立可量化、可验证的减碳计算模型
2. **数据驱动的精确计算**：充分利用现有数据，实现精确的减碳量计算
3. **系统化集成**：与现有系统（如meal_set_baseline）深度集成，形成完整的碳足迹计算体系
4. **可扩展和可维护**：设计灵活的配置体系，便于后续根据最新研究更新模型参数

## 二、现状分析

### 2.1 当前系统功能

- ✅ 员工素食数据管理（基本信息、素食类型、素食开始年份）
- ✅ 客户素食行为记录（素食类型、素食年限、订单关联）
- ✅ 基础统计数据（素食比例、类型分布、年限分布）
- ✅ 减碳效应分析（基于简化模型：固定2.0 kg CO₂e/天/人）
- ✅ 报表导出功能（Excel/PDF、ESG报告）
- ✅ 系统已有meal_set_baseline（一餐饭基准值）功能，可用于建立饮食碳排放基准

### 2.2 当前计算模型的问题

#### 核心问题

1. **参数过于简化**：使用固定值2.0 kg CO₂e/天/人，未区分素食类型
2. **缺乏基准对比**：只计算绝对减碳量，未与标准饮食基准对比
3. **客户计算不合理**：使用50%固定系数和30天订单调整，缺乏依据
4. **年限计算粗糙**：客户使用年限范围估算，未充分利用精确年份
5. **未利用现有系统**：未与meal_set_baseline集成，未能利用已有的饮食基准数据
6. **缺乏数据验证**：无数据质量评估和模型验证机制
7. **参数不可配置**：计算参数硬编码，难以根据最新研究更新

## 三、科学研究数据基础

### 3.1 权威研究数据汇总

**1. 饮食碳排放基准值（中国地区）**

- 杂食者日均碳排放：约 **4.5-5.5 kg CO₂e/天**（根据中国饮食习惯调整）
- 参考：联合国粮农组织数据、中国居民营养与健康状况调查

**2. 素食饮食减碳效果**

- **纯素（Vegan）**：减少约 **50-60%** 碳排放
- **蛋奶素（Ovo-lacto vegetarian）**：减少约 **40-50%** 碳排放
- **弹性素（Flexitarian）**：减少约 **20-30%** 碳排放
- **参考来源**：格拉纳达大学研究、冰岛研究等

**3. 不同素食类型的日均碳排放**

- 纯素：约 2.0-2.5 kg CO₂e/天
- 蛋奶素：约 2.5-3.0 kg CO₂e/天
- 弹性素：约 3.5-4.0 kg CO₂e/天

### 3.2 计算模型理论基础

**核心公式**：

```javascript
减碳量 = (标准饮食日均碳排放 - 素食饮食日均碳排放) × 素食天数
```

**其中**：

- 标准饮食日均碳排放：来自基准值库（支持地区差异）
- 素食饮食日均碳排放：基准值 × (1 - 素食类型减碳系数)
- 素食天数：基于素食开始年份精确计算（优先）或年限范围估算（备选）

### 4.2 计算逻辑重构

#### 4.2.1 新的减碳计算公式

**员工减碳计算**：

```javascript
// 1. 获取基准值和系数
const baselineEmission = await getBaselineEmission(region)  // 标准饮食日均碳排放
const reductionCoefficient = await getReductionCoefficient(vegetarianType)  // 素食类型减碳系数

// 2. 计算素食日均碳排放
const vegetarianDailyEmission = baselineEmission * (1 - reductionCoefficient)

// 3. 计算日均减碳量
const dailyReduction = baselineEmission - vegetarianDailyEmission
// 等价于：dailyReduction = baselineEmission * reductionCoefficient

// 4. 计算素食天数（优先使用精确日期）
let vegetarianDays = 0
if (vegetarianStartDate) {
  vegetarianDays = Math.floor((currentDate - vegetarianStartDate) / (1000 * 60 * 60 * 24))
} else if (vegetarianStartYear) {
  const startDate = new Date(vegetarianStartYear, 0, 1)
  vegetarianDays = Math.floor((currentDate - startDate) / (1000 * 60 * 60 * 24))
} else {
  // 无数据时使用默认值
  vegetarianDays = DEFAULT_VEGETARIAN_YEARS * 365
}

// 5. 计算总减碳量
const totalReduction = dailyReduction * vegetarianDays
```

**客户减碳计算**：

```javascript
// 与员工计算逻辑相同，但考虑以下因素：

// 1. 客户素食频率调整（可选，需要更多数据支撑）
let frequencyFactor = 1.0
if (vegetarianFrequency === 'weekly') {
  frequencyFactor = 0.5  // 每周素食，按50%计算
} else if (vegetarianFrequency === 'occasional') {
  frequencyFactor = 0.3  // 偶尔素食，按30%计算
}

// 2. 如果客户有订单记录，可以用订单验证素食频率
// （可选功能，需要订单与素食类型的关联数据）

// 3. 最终计算
const totalReduction = dailyReduction * vegetarianDays * frequencyFactor
```



#### 4.2.2 对比分析计算

**计算"如果改为标准饮食"的碳排放**：

```javascript
// 如果改为标准饮食的碳排放
const standardEmission = baselineEmission * vegetarianDays

// 减碳比例
const reductionRatio = (totalReduction / standardEmission) * 100

// 等效对比

const equivalentCarKm = totalReduction / 0.2  // 相当于减少汽车行驶（每km约0.2kg）
```



### 4.3 数据质量与验证机制

#### 4.3.1 数据质量评估

**质量等级定义**：

- **precise_date**：有精确的素食开始日期（最高质量）
- **precise_year**：有精确的素食开始年份
- **range_estimate**：只有年限范围估算
- **incomplete**：数据不完整（最低质量）

**质量评估逻辑**：

```javascript
function assessDataQuality(staff) {
  if (staff.vegetarianInfo.vegetarianStartDate) {
    return 'precise_date'
  } else if (staff.vegetarianInfo.vegetarianStartYear) {
    return 'precise_year'
  } else {
    return 'incomplete'
  }
}
```

**计算时的质量权重**（可选）：

```javascript
const qualityWeights = {
  precise_date: 1.0,
  precise_year: 0.95,
  range_estimate: 0.85,
  incomplete: 0.7
}

// 加权计算（可选，需要谨慎使用）
weightedReduction = totalReduction * qualityWeights[dataQuality]
```



#### 4.3.2 数据验证规则

1. **年限合理性检查**：

- 素食开始年份不能大于当前年份
- 素食开始日期不能大于当前日期
- 素食年限不能超过用户年龄（如有年龄数据）

2. **数据一致性检查**：

- 如果同时有年份和日期，日期必须与年份一致
- 素食类型与isVegetarian字段必须一致

3. **异常数据标记**：

- 素食年限超过50年标记为异常（需人工审核）
- 素食开始年份早于1900年标记为异常

// 从meal_set_baseline计算日均碳排放
async function calculateDailyEmissionFromBaseline(region, mealTime) {
  const baseline = await getMealSetBaseline(region, mealTime)
  // 假设：日均碳排放 = 早餐基准 + 午餐基准 + 晚餐基准 + 其他

                        baseline.breakdown.dish + 
                        baseline.breakdown.soup + 
                        baseline.breakdown.drink
  return dailyEmission
}
